# Meriem Boualam - Creative Portfolio

This is the professional portfolio website for Meriem Boualam, a creative director and visual artist based in Marrakesh, Morocco. The portfolio showcases her work across multiple services including photography, video production, and advertising campaigns.

## Key Features Implemented

1. **Personal Information**
   - Updated name, role, location and contact details
   - Replaced default avatar with Meriem's photo
   - Added multilingual support (English, French, Arabic)

2. **Content Sections**
   - Home page with creative introduction
   - About section detailing work experience in photography, video production and advertising
   - Gallery showcasing portfolio pieces
   - SEO-optimized content for better discoverability

3. **SEO Optimization**
   - Updated meta descriptions and titles
   - Configured proper schema data
   - Set up correct base URL for the domain
   - Optimized content for relevant keywords

4. **Navigation & Structure**
   - Organized navigation routes for multiple service categories
   - Created service-specific sections that showcase photography, video, and advertising work
   - Integrated social media profiles with professional links

5. **Technical Setup**
   - Updated configuration files for proper SEO
   - Maintained responsive design patterns
   - Preserved the Once UI framework structure while customizing it for Meriem's needs

## Services Offered

- Professional Photography (Documentary, Fashion, Portrait, Event)
- Video Production & Direction 
- Advertising Campaigns and Creative Direction
- Visual Content Creation for Brands and Publications

The portfolio is designed to showcase Meriem's creative storytelling abilities through visual media while maintaining a professional online presence optimized for search engines.
